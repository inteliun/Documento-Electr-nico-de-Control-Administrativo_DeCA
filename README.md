# Documento-Electr-nico-de-Control-Administrativo_DeCA
DeCA (Documento Electrónico de Control Administrativo) es la versión digital obligatoria del documento de control que debe acompañar a los servicios de transporte público de mercancías por carretera y de viajeros dentro de España. Su uso es obligatorio en formato digital desde el 5 de octubre de 2026 (según la Ley 9/2025 de movilidad sostenible).
